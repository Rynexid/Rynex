# UI/UX Design Showcase

Kumpulan dokumentasi desain UI/UX yang terbagi dalam 2 kategori utama: **Dashboard** dan **eCommerce Storefront**. Setiap project memiliki README.md sendiri di dalam foldernya, berisi judul, deskripsi singkat, tujuan, fitur utama, dan daftar file.

## Struktur Folder

```
showcase/
├── Dashboard/
│   ├── HRDashboard/
│   │   └── Ocupite/            → HR Dashboard (dark mode + AI chat)
│   ├── Sales Analytics/
│   │   ├── CRM/
│   │   │   └── Dealstack/      → CRM Dashboard (pipeline & deal tracking)
│   │   └── SRM/
│   │       └── codename/       → SRM Dashboard (dengan video demo komponen)
│   └── eCommerce/
│       ├── ConfidencyOS/       → eCommerce Admin Dashboard (responsive)
│       └── Ecomiq/             → eCommerce Analytics Dashboard (live visitor)
└── eCommerce/
    ├── Sublime/                → Storefront minimalis
    ├── Belo-fur/               → Storefront fashion/aksesoris
    ├── Ovalen/                 → Storefront (2 varian homepage + video fitur)
    ├── Piccollo/                → Storefront lengkap (collection + detail produk)
    └── CozyPaws/                → Storefront produk hewan peliharaan
```
