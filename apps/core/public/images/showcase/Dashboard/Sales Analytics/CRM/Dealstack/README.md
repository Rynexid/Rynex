# Dealstack — CRM Dashboard

**Kategori:** Dashboard / Sales Analytics / CRM
**Tema:** Light Mode

## Deskripsi Singkat
Dashboard CRM yang berfokus pada pengelolaan deal/penjualan, menampilkan ringkasan pipeline dan status transaksi dalam tampilan bersih bertema terang.

## Tujuan
Membantu tim sales memonitor progres deal, melacak status pipeline, dan mengambil keputusan cepat berdasarkan data penjualan yang terstruktur.

## Fitur Utama
- Ringkasan pipeline deal secara visual
- Tampilan fullview untuk analisis menyeluruh
- Zoom detail pada fitur-fitur kunci (deal card, status tracker)
- Layout bersih dengan hierarki informasi yang jelas
