# Codename — SRM Dashboard

**Kategori:** Dashboard / Sales Analytics / SRM
**Tema:** Light Mode

## Deskripsi Singkat
Dashboard Supplier/Sales Relationship Management (SRM) dengan komponen interaktif yang didemonstrasikan lewat video showcase, menampilkan alur kerja dan interaksi UI secara langsung.

## Tujuan
Memberikan gambaran menyeluruh tentang pengelolaan relasi supplier/sales melalui antarmuka yang informatif, sekaligus mendemonstrasikan interaksi micro-animation lewat video.

## Fitur Utama
- Video demo komponen interaktif (2 klip showcase)
- Tampilan dashboard utama dengan ringkasan data relasi
- Mockup produk untuk keperluan presentasi
- Detail zoom pada elemen antarmuka penting
