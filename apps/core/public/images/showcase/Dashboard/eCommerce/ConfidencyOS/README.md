# ConfidencyOS — eCommerce Admin Dashboard

**Kategori:** Dashboard / eCommerce
**Tema:** Light Mode, Responsive

## Deskripsi Singkat
Dashboard admin untuk platform eCommerce yang dirancang responsif di berbagai perangkat, mencakup manajemen produk, order, dan ringkasan performa toko.

## Tujuan
Memberikan pemilik/admin toko online kendali penuh atas operasional harian—mulai dari pemantauan penjualan hingga manajemen data—melalui satu dashboard yang konsisten di desktop maupun mobile.

## Fitur Utama
- Desain responsif (mockup laptop, tablet, dan handphone tersedia)
- Tampilan tabel data yang rapi untuk manajemen produk/order
- Ringkasan performa toko di halaman utama
- Konsistensi visual antar breakpoint perangkat
