# Ecomiq — eCommerce Analytics Dashboard

**Kategori:** Dashboard / eCommerce
**Tema:** Light Mode

## Deskripsi Singkat
Dashboard analitik eCommerce dengan fitur pemantauan pengunjung secara langsung (live visitor) dan laporan performa toko dalam tampilan modular.

## Tujuan
Membantu pengelola toko online memahami perilaku pengunjung secara real-time dan mengevaluasi performa penjualan melalui laporan yang mudah dibaca.

## Fitur Utama
- Live visitor tracking (didemonstrasikan lewat video)
- Modul laporan (report) performa toko
- Komponen UI reusable (components, components2)
- Detail halaman produk (detail view)

## Isi Folder
| File | Keterangan |
