# Ocupite — HR Dashboard (Dark Mode)

**Kategori:** Dashboard / Human Resources
**Tema:** Dark Mode

## Deskripsi Singkat
Dashboard HR bertema gelap yang dilengkapi asisten AI untuk membantu tim HR mengelola data karyawan, komunikasi, dan operasional harian dalam satu tampilan yang rapi dan modern.

## Tujuan
Mempermudah tim HR memantau data karyawan dan menjalankan tugas administratif melalui satu panel terpusat, dengan bantuan AI chat untuk mempercepat pencarian informasi atau eksekusi tugas.

## Fitur Utama
- Sidebar navigasi utama untuk akses cepat antar modul HR
- Panel AI Chat terintegrasi untuk query & bantuan cepat
- Tampilan komponen UI modular (cards, list, chat bubble)
- Skema warna dark mode dengan aksen kontras tinggi untuk kenyamanan mata
