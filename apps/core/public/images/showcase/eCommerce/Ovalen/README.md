# Ovalen — eCommerce Storefront

**Kategori:** eCommerce / Storefront
**Tema:** Light Mode

## Deskripsi Singkat
Storefront eCommerce dengan variasi tampilan halaman utama (v1 & v2) serta demo fitur unggulan lewat video, menampilkan pendekatan iteratif dalam desain produk.

## Tujuan
Menyajikan pengalaman berbelanja yang meyakinkan dengan variasi tampilan yang bisa diuji, serta menyoroti fitur unggulan secara interaktif lewat video showcase.

## Fitur Utama
- Dua varian tampilan halaman utama (home v1 & v2)
- Video demo fitur unggulan (homefeat)
- Mockup presentasi produk & fitur
- Detail zoom pada fitur tertentu

## Isi Folder
| File | Keterangan |
|---|---|
| `home.webp` | Tampilan utama storefront (v1) |
| `homev2.webp` | Tampilan utama storefront (v2) |
| `fullview.webp` | Tampilan penuh halaman |
| `mockup.webp`, `mockupfeat.webp`, `mockuphome.webp` | Mockup presentasi produk & fitur |
| `zoomfeat.webp` | Detail zoom fitur unggulan |
| `homefeat.mp4` | Video demo fitur unggulan halaman utama |
