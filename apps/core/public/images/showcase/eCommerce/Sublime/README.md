# Sublime — eCommerce Storefront

**Kategori:** eCommerce / Storefront
**Tema:** Light Mode, Minimalis

## Deskripsi Singkat
Tampilan storefront eCommerce dengan gaya minimalis, menonjolkan produk melalui layout bersih dan mockup presentasi di perangkat laptop.

## Tujuan
Menghadirkan pengalaman belanja online yang sederhana namun elegan, dengan fokus pada visual produk dan kemudahan navigasi.

## Fitur Utama
- Layout minimalis dengan whitespace yang seimbang
- Mockup tampilan di laptop untuk presentasi konteks penggunaan
- Fokus pada showcase produk di halaman utama
