# Belo-fur — eCommerce Storefront

**Kategori:** eCommerce / Storefront (Fashion)
**Tema:** Light Mode

## Deskripsi Singkat
Storefront eCommerce untuk brand fashion/aksesoris, menampilkan produk secara visual menarik dengan tata letak yang mengutamakan estetika brand.

## Tujuan
Membangun identitas brand fashion yang kuat lewat tampilan storefront yang stylish, sekaligus memudahkan pengunjung menemukan produk unggulan di halaman utama.

## Fitur Utama
- Fullview halaman untuk melihat keseluruhan alur desain
- Fokus pada visual produk sebagai daya tarik utama
- Layout yang mendukung branding fashion
