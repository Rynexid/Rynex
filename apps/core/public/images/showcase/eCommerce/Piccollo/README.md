# Piccollo — eCommerce Storefront

**Kategori:** eCommerce / Storefront
**Tema:** Light Mode

## Deskripsi Singkat
Storefront eCommerce paling lengkap di showcase ini, mencakup halaman koleksi, detail produk, dan video demo interaksi halaman utama.

## Tujuan
Menyediakan alur belanja end-to-end yang utuh—dari halaman koleksi hingga detail produk—untuk menunjukkan bagaimana pengalaman pengguna dirancang secara menyeluruh.

## Fitur Utama
- Halaman koleksi produk (collection page)
- Halaman detail produk yang informatif
- Video demo interaksi halaman utama (homefeat)
- Mockup presentasi untuk halaman utama & detail produk
